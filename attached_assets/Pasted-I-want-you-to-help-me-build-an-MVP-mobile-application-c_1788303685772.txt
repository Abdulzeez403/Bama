I want you to help me build an MVP mobile application called "HausaBridge".

PROJECT PURPOSE

HausaBridge is a mobile communication app designed to help English-speaking NYSC corps members, teachers, volunteers and visitors communicate with Hausa-speaking students and people in local communities.

The real problem is that corps members and teachers sometimes struggle to communicate with students and community members because they do not understand Hausa well.

The MVP should focus on practical English ↔ Hausa communication rather than being a generic language-learning application.

TECH STACK

- React Native
- Expo
- TypeScript
- Expo Router for navigation
- Use a clean component-based architecture
- Use local data for the MVP
- The application should work offline for the core phrasebook
- Do NOT create a backend yet unless it is necessary
- Structure the code so a Node.js/Express backend can easily be added later

IMPORTANT

Do not over-engineer the MVP.

I want a working, polished mobile application that I can install on my Android phone and test with real students and community members.

DESIGN

Create a modern, simple and friendly mobile UI.

The application should feel like a practical communication tool, not a school textbook.

Use:
- Clean cards
- Large readable text
- Large touch targets
- Simple icons
- Good spacing
- Accessible typography
- Bottom navigation where appropriate
- Smooth but subtle animations

The UI should work well on low-to-mid-range Android phones.
